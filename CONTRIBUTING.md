# Contributing to ai-clone-playbook

Thanks for your interest in improving this playbook. This repo collects
open-source guides for AI cloning (voice, video, lip-sync, avatars).

## Ways to contribute

- **Fix or improve a guide** — corrections, clearer steps, better examples.
- **Add a new tool** — open-source only, with a link and a one-line description.
- **Report a problem** — open an issue describing what's unclear or wrong.
- **Suggest a topic** — open an issue with the guide you'd like to see.

## Guidelines

1. **Open-source only.** No links to closed-source SaaS tools as the primary
   recommendation. Paid/hosted options may be mentioned only as alternatives.
2. **One topic per guide.** Keep each file focused; link to related guides
   instead of duplicating content.
3. **Cite sources.** Link to the model's repo, paper, or official docs.
4. **Respect ethics & law.** Every guide must include a short
   "Ethics & legal notes" section (consent, likeness rights, disclosure).
5. **Keep it reproducible.** Include hardware requirements, install steps,
   and a minimal working example where possible.

## Workflow

1. Fork the repo and create a branch:
   `git checkout -b guide/your-topic`
2. Make your changes. Use Markdown, UTF-8, LF line endings.
3. Commit with a clear message:
   `git commit -m "Add: short description"`
4. Push and open a pull request against `main`.
5. Describe what you changed and why in the PR.

## File layout

- `guides/` — numbered guides (`01-voice-cloning.md`, ...)
- `resources/` — tool lists and references
- Keep the README's "What's inside" links in sync when adding guides.

## Code of conduct

Be respectful. No harassment, no non-consensual cloning content, no
instructions for impersonation or fraud.
